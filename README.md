# راه‌یاب — پیش‌نمایش فروشگاه قطعات خودرو

این نسخه استاتیک برای دیدن ظاهر فروشگاه روی گوشی و انتشار رایگان در GitHub Pages ساخته شده است.

## انتشار با گوشی
1. فایل ZIP را در گوشی دانلود و استخراج کن.
2. در [GitHub](https://github.com/new) یک مخزن Public به نام `rahyab-auto-parts` بساز.
3. در مخزن روی **Add file → Upload files** بزن و فایل‌های داخل پوشه را آپلود کن. `index.html` باید در ریشه مخزن باشد.
4. **Commit changes** را بزن.
5. به **Settings → Pages** برو.
6. در بخش **Build and deployment** گزینه **Deploy from a branch**، شاخه `main` و پوشه `/(root)` را انتخاب و Save کن.
7. پس از چند دقیقه، لینک سایت در همان صفحه نمایش داده می‌شود.

## توجه
این نسخه برای نمایش طراحی و تعامل‌های ساده مرورگر است. سبد خرید و فرم‌ها نمایشی‌اند؛ این نسخه استاتیک بک‌اند Node.js، SQLite، حساب کاربری امن، مدیریت واقعی محصولات یا پرداخت واقعی ندارد. برای آن امکانات باید پروژه سرورمحور را روی میزبانی Node.js منتشر کرد.

## English
A responsive Persian RTL static preview for GitHub Pages. Upload files to a repository and enable **Settings → Pages → Deploy from a branch → main → /(root)**. The backend, database, real user accounts and payments are not included in this static preview.
